# План реализации фронтенда MikuroECOV2

Этот документ описывает пошаговый процесс трансформации текущего прототипа в полноценное приложение согласно [ARCHITECTURE.md](./ARCHITECTURE.md).

## Этап 1: Инфраструктура и Базовая Настройка

1.  **Настройка Routing (Vue Router):**
    *   Заменить ручное переключение `activeTab` в `App.vue` на `<router-view>`.
    *   Создать структуру в `src/views/` (Home, Login, Register, Profile, PostView, Admin).
    *   Настроить маршруты в `src/router/index.js`.
2.  **Глобальное состояние (Pinia):**
    *   Создать `auth.js` для хранения данных пользователя и токенов.
    *   Создать `posts.js` для управления лентой и кэширования постов.
3.  **HTTP Клиент (Axios):**
    *   Настроить инстанс Axios с `baseURL`.
    *   Добавить интерцептор для обработки ошибок 401 (Refresh Token flow).
    *   Настроить `withCredentials: true` для работы с secure cookies.

## Этап 2: Аутентификация и Безопасность

1.  **Компоненты Auth:**
    *   Реализовать `UserAuthForm.vue` (общий для Login/Register).
    *   Интеграция виджета CAPTCHA.
    *   Валидация полей через `VeeValidate` или `Zod`.
2.  **Защита маршрутов (Guards):**
    *   Реализовать `Navigation Guards` в роутере для проверки ролей (`guest`, `user`, `admin`).
    *   Создать компонент-обертку `RoleGuard.vue` для скрытия элементов UI на основе прав.

## Этап 3: Лента и Контент

1.  **Основа ленты (PostFeed):**
    *   Переработать `Roll.vue` в динамический `PostList.vue`.
    *   Реализовать компонент `PostCard.vue` с поддержкой различных типов контента.
    *   Добавить бесконечную прокрутку (Infinite Scroll) или пагинацию.
2.  **Просмотр поста:**
    *   Интеграция Markdown парсера (например, `marked` + `DOMPurify` для XSS защиты).
    *   Медиа-галерея для фото и видео плеера.
3.  **Создание/Редактирование (Editor):**
    *   Реализовать `PostEditor.vue`.
    *   Загрузка файлов (drag-and-drop) на S3 через API.
    *   Превью Markdown в реальном времени.

## Этап 4: Взаимодействие (Социальный слой)

1.  **Комментарии:**
    *   Реализовать древовидную или плоскую структуру комментариев.
    *   Компонент `CommentForm.vue` с валидацией.
2.  **Реакции:**
    *   Компонент `ReactionButtons.vue`.
    *   Оптимистичное обновление UI (изменение счетчика до подтверждения сервером).

## Этап 5: Профиль и Администрирование

1.  **User Profile:**
    *   Экран настроек (смена аватара, био).
    *   Просмотр постов конкретного пользователя.
2.  **Admin Panel:**
    *   Таблица управления пользователями.
    *   Инструменты модерации (удаление постов/комментариев).

## Этап 6: Полировка и Деплой

1.  **UI/UX:**
    *   Добавить Skeleton Loaders для загрузки данных.
    *   Обработка оффлайн-режима и ошибок сети (Toast уведомления).
    *   Адаптивная верстка (проверка на мобильных устройствах).
2.  **Тестирование:**
    *   Unit-тесты для хранилищ Pinia (Vitest).
    *   E2E тесты критических путей: Регистрация -> Пост -> Комментарий (Playwright).
3.  **Docker & CI/CD:**
    *   Актуализировать `Dockerfile` и `nginx.conf` под SPA.
    *   Настроить автоматическую сборку и проверку линтером (ESLint/Prettier).
