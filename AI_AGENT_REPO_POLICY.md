# AI Agent Repository Policy

Этот файл описывает поведение ИИ-агента при работе с данным проектом.

- Репозиторий: <https://github.com/BULKkA/MikuroECOV2>
- Все изменения, которые делает ИИ-агент, должны коммититься и пушиться именно в этот репозиторий.
- Все исходные данные, история и состояние проекта считываются из этого репозитория.
- При запуске агент должен выполнять:
  1. `git fetch origin`
  2. `git pull origin main` (или основная ветка проекта, если отличается)
  3. работать с локальной копией
  4. `git add .`, `git commit -m "<сообщение>"`, `git push origin main`

> Важно: прежде чем публиковать изменения, убедитесь, что выполнены все проверки качества (тесты, сборка, lint).
